# Kürzel-Liste für den Zuchtstall

So schreibst du mir, wo etwas im Spiel ist. Unterbereiche einfach ausschreiben,
z. B. „pmk - Pferdehändler“ oder „asr - Putzkiste“.

## Allgemein
| Kürzel | Was ist gemeint |
|---|---|
| **Hauptmenü** oder **hm** | das Hauptmenü |
| **Startmenü** oder **start** | das Startmenü (Spiel starten/laden) |
| **Menü** | die drei Striche ☰ oben rechts (Hauptmenü, Postfach, Vollbild, Sparmodus, Enzyklopädie) |
| **Brief-Popup** | ein Brief, den du über den gelben Umschlag oben rechts öffnest |
| **Rücksprung** | nach einer Aktion (fertig oder abgebrochen) landet man wieder dort, wo man sie gestartet hat |

## Stall und Box
| Kürzel | Weg |
|---|---|
| **Stall** | hm - Stall (Übersicht aller Boxen) |
| **Box** | hm - Stall - Box |
| **Steckbrief** oder **stb** | Box - Steckbrief |
| **Daten** | Box - stb - Daten |
| **Genetik** | Box - stb - Genetik |
| **Aufschlüsselung** oder **afs** | Box - stb - Aufschlüsselung |
| **Gangwerk** oder **gw** | Box - stb - Gangwerk |
| **Charakter** | Box - stb - Charakter |
| **Ausbildung** oder **asb** | Box - stb - Ausbildung (der *Ausbildungsstall* wird immer ausgeschrieben) |
| **Pferdepflege** oder **ppf** | Box - Pferdepflege |
| **Versorgung** oder **vsg** | Box - ppf - Versorgung |
| **Ausrüstung** oder **asr** | Box - ppf - Ausrüstung |
| **Ort** | Box - ppf - Ort |
| **Test** | Box - ppf - Test (nur im Adminmodus) |
| **Pferdeanhänger** oder **pah** | BEIDE Anhänger: Box - ppf - Ort - Pferdeanhänger *und* hm - Pferdeanhänger. Sie sind immer gleich, nur der im hm hat die Mehrfachauswahl. |

## Beispiele
- „**asr - Putzkiste**: Der Kamm soll …“
- „**pmk - Auktionshaus**: Die Gebote sollen …“
- „**pah - Klinik**: neue Behandlung …“ (gilt automatisch für beide Anhänger)
- „Nach dem Verkaufen bitte **Rücksprung** zum pah.“
