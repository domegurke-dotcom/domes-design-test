# Animationstool (Dome + Claude Team, Start 31.10.2026)

Ziel: 2D-Animationstool für die Spielpferde. Die Gelenke sind verschiebbare Punkte; damit werden Bewegungsabläufe (Schritt, Trab, Galopp, Tölt, Pass, Running Walk …) erstellt und nachgebildet – mit Fußfolge (aufsetzen, belasten, abfußen, Schwebephase), Schrittlängen/-abständen wie in Domes PDFs (`pdfs/`, u. a. Tennessee Walking Horse, Icelandic Horse).

Stand: nur Ordner und Plan, noch nichts gebaut (wartet auf Domes OK und die PDF zu Bewegungsabläufen).
